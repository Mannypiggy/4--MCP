## 3. MCP 数据源与分工

### 3.1 领星 MCP：内部经营结果

领星 MCP 用于查询：

- 产品表现：销量、销售额、Sessions、Page Views、Total CVR；
- 广告表现：曝光、点击、CTR、CPC、花费、广告订单、广告销售额、ACOS、ROAS；
- 利润表现：利润、利润率、广告花费占比及相关费用；
- 库存表现：FBA 可售库存、在途库存和库存风险；
- 商品信息：店铺、SKU、ASIN、实际售价及可获取的促销信息。

### 3.2 SIF MCP：外部市场与流量原因

SIF MCP 用于解释领星内部经营数据发生变化的外部原因，包括：

- 核心关键词搜索需求及趋势；
- 自然排名和广告排名变化；
- ASIN 流量来源及关键词结构；
- 指定竞品的流量词、排名和流量份额变化；
- 本品与指定竞品在核心关键词上的差距；
- 新增、下降或流失的主要流量词。

SIF 查询规则：

- 优先查询本文件“指定对标竞品名单”中的竞品 ASIN；
- 不得自行替换或扩展竞品名单；
- 没有指定竞品的型号，标注“暂无指定竞品”，不得自行添加；
- 竞品实时售价只有在已授权数据源明确返回时才可引用，无法取得时使用本文件的促销价格和用户提供的竞品价格，不得推测。

### 3.3 领星与 SIF 联动流程

1. 领星判断销量、Sessions、Total CVR、广告或利润是否异常；
2. 对异常型号使用 SIF 查询关键词需求、排名、流量来源和指定竞品变化；
3. 区分内部经营问题、外部市场问题、价格促销影响、Buy Box 影响和变体流量转移；
4. 给出有数据依据的操作建议；
5. 记录建议执行日期，在后续周期复查操作前后变化。

输出结论须区分：

- 【领星数据依据】
- 【SIF 市场依据】
- 【特殊情况/价格依据】
- 【综合判断】
- 【操作建议】

不得将推测描述为确定事实。

## 10. 输出要求

### 10.1 会议一页摘要

1. 本期整体：销量、Sessions、Total CVR、7月全月目标完成率。
2. 同比：销量、Sessions、Total CVR，对比期固定为 2025-06-01 至 2025-06-20。
3. 不输出环比数据、环比图表或环比结论。
4. 重点型号：五个组分别独立成图或卡片。
5. 每个重点型号组包含：
   - 2026-07-01 至 2026-07-20 销量；
   - 7月全月目标及完成率；
   - Sessions、Total CVR 本期值；
   - 销量、Sessions、Total CVR 的指定同比；
   - 本品实际价格、促销形式、参考价/Deal 标/Buy Box 特殊情况；
   - 指定竞品表现；
   - 简洁的经营原因与行动建议。
6. 其他型号单独汇总，至少展示销量、7月全月目标和完成率。
7. 月会额外内容：广告花费占比、利润情况及分析结论。

### 10.2 重点异常说明

以下情况必须重点解释：

- 销量明显低于预期；
- Sessions 或 Total CVR 明显下降；
- 广告曝光、点击、花费、广告销售额或 ACOS 明显变化；
- 发生价格、Deal 标、参考价或 Promotion 变化；
- 丢失或恢复购物车；
- 广告数据缺失；
- SIF 显示核心关键词需求、排名或竞品流量明显变化。

## 11. 计算口径与数据校验

- 目标完成率 = 本期销量 ÷ 7月全月目标 × 100%。
- 同比变化率 =（本期值 - 指定对比期值）÷ 指定对比期值 × 100%。
- 本次指定同比为 2026-07-01 至 2026-07-20 对比 2025-06-01 至 2025-06-20。
- 本次不计算环比。
- 没有查询结果不等于数值为 0。
- Sessions 或 Page Views 为 0 但存在订单时，标记为数据可能未更新。
- H1060P-带OTG 7/6-7/7 广告数据缺失，广告前后对比时必须排除或单独标注。
- 当领星、SIF、广告、产品表现和利润数据更新时间不一致时，必须注明。
- 同一 SKU 或 ASIN 不得重复计入多个型号组。
- 跨店铺销售的同一型号应先分店铺查询，再按任务要求汇总。
- 无法取得的数据统一标记为”未返回””数据未更新””映射关系待确认”或”当前授权范围不支持”，不得自行补值。

### 11.1 同比环比扩展指标

- **CVR 同比**：整体摘要和每个重点型号组必须输出 Total CVR 同比对比（本期 CVR vs 同比期 CVR）。
- **B2B 销量/销售额**：整体摘要和每个重点型号组必须输出 B2B 销量（b2b_order_items）和 B2B 销售额（b2b_amount），并做同环比。
- 领星字段：`b2b_order_items`、`b2b_amount`、`cvr`（或 `order_items ÷ sessions`）。

### 11.2 广告数据汇总规则

以下型号组广告数据必须汇总为一个整体进行同环比：

**Kamvas 13 (Gen 3) 系列（第一组）：**
- 广告只打黑色款（GS1333-Black-Stand）
- 广告汇总 = 黑色款 + 粉色款（粉色通常为0），汇总 spend/impressions/clicks/ad_sales/ACOS/ROAS

**H951P / H641P 系列（第五组）：**
- 只打广告 H951P-黑色 和 H641P-灰樱粉
- 广告汇总 = H951P-黑色 + H641P-灰樱粉

### 11.3 竞品数据完整性

- **先查询，后生成**：所有指定对标竞品的 SIF 数据必须全部查询完毕并写入 HTML 后方可交付，不允许先生成含占位的 HTML 再补数据
- **先查询本品，再查竞品**：每个重点型号组先查本品 SIF `market_get_asin_keyword_signals`，再查竞品，确保核心关键词排名成对出现
- **禁止占位文字**：最终 HTML 中不得出现”未单独返回该词份额””SIF数据待补充””SIF竞品详细数据待后续补充查询”等；无法获取的数据标注具体原因（”ASIN已下架””当前授权范围不支持”）
- 竞品给出关键词排名时，本品必须对应查询并列出同词排名（竞品排名镜像规则）
- B07L77GTTY（Wacom Cintiq 16）已下架，后续竞品分析排除该 ASIN
- Q630M 的 ASIN 映射为 B0B1V1JBNX（Inspiroy Dial 2）
